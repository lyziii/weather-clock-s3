# ESP32-S3 Weather Clock

基于 ESP-IDF 和 LVGL 的触摸天气时钟、骑行码表与 IMU 姿态显示工程。

## 功能

- 时钟、天气、骑行码表和 MPU6050 姿态诊断。
- 右滑依次切换 Clock、System、Ride，左滑返回；首尾不循环，IMU 不再独占一级标签。
- 翻页圆点短暂显示后淡出，三页采用全屏布局。
- System（系统）一级页提供 Music、TF 容量与文件、Gyroscope、Magnetometer、GPS、WiFi、USB Disk 和屏幕亮度滑条；菜单可上下滑动并显示滚动条，视频仍不可用。亮度设置写入 NVS，重启后保持；最低限制为 10%，避免误调到黑屏。
- WiFi 二级页提供触摸屏配置：点击 SCAN 扫描附近热点、点击网络自动填入 SSID，或点 MANUAL 手动输入；自带全屏触摸键盘（字母、大小写、数字符号、退格、空格），输入 SSID 与密码后点 CONNECT 连接，结果实时显示在状态行。串口 `config` 配置仍可用。
- 陀螺仪二级页保留三轴加速度、角速度、姿态图和诊断状态，可纵向滚动查看；地磁计页采用固定顶部指示箭头、旋转方位/角度刻度盘和盘上方中文角度读数，融合陀螺仪快速积分与低通磁航向；静止时加强平滑以抑制抖针，转动时加快航向收敛。向上滑动可查看三轴磁场及诊断。GPS 页显示定位与收发诊断；中文字库加载后显示中文状态、RX/TX 字节、有效 NMEA 语句数和校验错误，定位状态包括搜星中。
- 二级页点击返回键或左滑回系统菜单，系统内容区上下滑动不会展开电源面板；从标题栏下拉仍可展开睡眠面板。
- TF 挂载成功后所有标题栏显示卡图标；后台检测拔出和重插，失败不自动格式化。
- 时钟页显示公历日期、星期与农历（农历需先加载中文字库）。
- 时钟页按区域排布：页头城市与状态图标、日期与星期同一行、农历、48 px 时间、天气卡片（图标+温度、天气描述、湿度）和数据来源；横屏时日期/星期/农历合并到一行，时间占满整行，天气卡片横向铺开。晴/云/雨/雪/雷五种图标放在同一个固定 62×52 槽位内，槽位左边缘始终为温度文字右边缘 +10 px、垂直中心与温度文字一致，横竖屏共用同一公式；动画只在槽位内部播放（太阳脉冲、雨滴/雪花下落、闪电闪烁），不再移动图标容器，因此切天气或转屏时图标位置不会跳动。
- TF 文件页显示文件系统总量、剩余量和已用量，支持目录进入、返回上级、列表滚动、分页和查看文件大小，不写入或删除文件。
- System 菜单的 USB Disk 按钮把 TF 卡切换为 USB OTG U 盘（MSC），电脑可直接读写卡内文件；设备端同时暂停本地 TF 浏览，再按一次退出并自动重新挂载。进入前会先读扇区 0 自检，自检失败立即退回本地挂载，因此电脑不会看到一个打不开的盘；中文字库已常驻 PSRAM，切换 U 盘不会影响中文显示。U 盘模式不会格式化卡，卡内原有 FAT 文件系统保持不变；此时 USB 口用于传输磁盘数据，原生 USB Serial/JTAG 串口日志会中断，退出 U 盘模式后恢复。退出前请先在电脑上「安全弹出」该磁盘，避免未落盘的写缓存丢失。音乐播放期间会暂缓切换 U 盘，停止播放或播放结束后即可正常切换。
- 冷启动及三击触摸唤醒后先显示横线展开、L-Vectra 渐显的约 1.8 秒动画，再显示保存的一级标签页。
- 码表页提供开始、暂停与二次确认清零；无有效传感器数据时显示未知值。
- MPU6050 读数有效时，仅时钟页自动旋转，系统及其子页、码表固定正向。无有效读数（未连接、读取失败或数据过期）时，下拉面板增加 `Rotate 90` 按钮，每次点击按 0° → 90° → 180° → 270° → 0° 循环，所有页面沿用手动方向。每次设置写入 NVS，下次上电或深睡唤醒后自动恢复，无需重新设置；传感器恢复后按钮隐藏并恢复原有自动旋转规则，保存的手动方向不清除。
- 正常运行时每次手指落屏播放一次短促触摸音，空白区域与禁用控件同样有效；长按或不离屏滑动不会连响。
- 连续传感器读数在硬件快照层按实际采样间隔低通：IMU 加速度/陀螺仪时间常数分别为 0.12/0.08 秒，地磁三轴 0.20 秒，GPS 位置/速度 0.80 秒、海拔 1 秒；GPS 丢失 fix 后重新初始化位置滤波，避免旧位置拖影。电压采样沿用每组 16 次均值，定位质量、卫星数等离散状态不做数值平均。
- Music 页可播放一段内置旋律，或自动播放 TF 卡 `/tf/music`（其次 `/tf` 根目录）中第一个 16 位 PCM WAV。WAV 支持 8～48 kHz、单/双声道，播放时线性重采样到 16 kHz；没有 WAV 时自动回退内置旋律。播放、停止均为异步命令，不阻塞触摸和界面。串口也可用 `music start` / `music stop` 验证喇叭。
- 时钟页天气不再等待 SNTP：WiFi 获取 IP 后立即请求；系统时间尚未校准时自动使用同一服务的 HTTP 接口，时间有效后回到 HTTPS。SNTP 失败会每 5 分钟重试。TLS 缓冲放在 PSRAM，避免 WiFi + 字库占用内部 RAM 后 mbedTLS 分配失败。

触摸音与音乐共用 ES8311 DAC 和 FM8002E 功放，PCM 由独立任务输出。初始音量参数 `HW_AUDIO_CLICK_VOLUME=60`，可在 [main/hardware_config.h](main/hardware_config.h) 调整（0～100），同时作用于触摸音、音乐和诊断音；修正接线后应从低音量逐步试听。音频初始化失败只关闭音频，不阻断界面。进入深睡前静音并保持功放 GPIO 为关闭电平；深睡三击门控期间不启动音频，完整唤醒后恢复。当前只使用喇叭输出，GPIO6 录音输入仍未启用。

TF 卡使用已有 FAT16/FAT32 文件系统（32 GB 卡通常为 FAT32）；不支持的格式会报告挂载错误，不改写卡。容量单位为 GiB，32 GB 标称卡显示约 29.8 GiB 属正常现象。文件系统 API 使用 UTF-8 长文件名；界面自带 Montserrat 仅含拉丁字形，TF 文件名与 WiFi 中文 SSID 通过 SD 卡中文字库显示（见下文）。二级页可点击返回键或左滑回系统首页。Music 页只读取 `/tf/music` 或根目录中的 WAV，不会写入卡；TF 文件页仍只浏览文件，不解码或播放。

中文字库使用 LVGL 二进制点阵格式，放在 TF 卡 `/fonts/ch16.bin`（卡根目录下 `fonts` 文件夹内）。设备挂载 TF 卡后，独立的低优先级任务先把整个文件读入 PSRAM，再通过 LVGL MEMFS 解析；LVGL 任务只读取已加载的字体指针，因此字库加载期间开机动画、触摸和天气请求都不会被阻塞。解析完成后文件句柄关闭，字形位图、字形描述符和字表常驻 PSRAM；之后拔卡、重新挂载或切换 U 盘都不影响已加载的中文。缺字回退 Montserrat 显示图标与英文。未放字库或加载失败时界面照常工作，中文显示为方框。生成命令示例（需 [lv_font_conv](https://github.com/lvgl/lv_font_conv) 与一款中文 TTF，覆盖 ASCII + CJK 常用汉字）：

```sh
lv_font_conv --font YourFont.ttf --size 16 --bpp 4 \
  -r 0x20-0x7E,0xA0-0xFF,0x2000-0x206F,0x3000-0x303F,0x4E00-0x9FA5,0xFF00-0xFFEF \
  --no-compress --format bin --output ch16.bin
```

范围写到 `0x4E00-0x9FA5` 而不是 `0x9FFF`，可避免未分配码位产生大量 missing glyph 警告。以 `simhei.ttf` 16 px / 4 bpp 实测：21169 个字形、约 2.6 MB（ASCII、全角标点、CJK 基本区全覆盖）；整体载入后字形描述符按 32 位索引存放，PSRAM 占用约 2.9 MB。去掉 `--no-compress` 可把文件压到约 2.2 MB，但每个字形绘制时多一次 RLE 解压，本工程需要 32 位字形索引，压缩带来的收益有限。

将生成的 `ch16.bin` 拷到 TF 卡 `/fonts/ch16.bin` 即可（加载器也依次尝试 `/font/ch16.bin` 与卡根目录 `/ch16.bin`）。首次重试失败时串口会以 `zh_font` 标签列出 `/tf`、`/tf/fonts`、`/tf/font` 的实际内容，便于确认路径；文件名必须是小写 `ch16.bin`。

放到卡里的三种方式：

1. 卡片已在设备内：点 System → USB Disk 进入 U 盘模式，电脑上打开可移动磁盘，在卡根目录新建 `fonts` 文件夹并拷入 `ch16.bin`，然后**右键「弹出/安全删除硬件」**，再在设备上点一次 USB Disk 退出。设备重新挂载 `/tf` 后约 3 秒内自动加载，串口打印 `zh_font: Chinese font loaded ... in ... ms`。加载在后台任务中完成，界面不会停顿；完成后下一次界面刷新自动切换到中文。
2. 取出 TF 卡用读卡器拷入，插回设备后自动挂载并重试加载（设备无卡座检测脚，靠 SD 状态命令周期探测）。
3. 烧录固件把字库编译进 Flash 不在支持范围内：当前实现只从 TF 卡读取一次并缓存到 PSRAM。

注意：U 盘模式下 USB 口用于传输磁盘数据，设备端串口日志会中断；未「安全弹出」就退出可能丢失 FAT 写缓存，表现为文件缺失或损坏。字库加载完成后文件句柄立即关闭，运行中拔卡不会影响已经显示的中文；重新插卡后文件浏览会自动恢复，已加载的字库无需重新读取。字库整文件读取和 WAV 播放期间会暂时阻止卡状态卸载和 U 盘切换，避免读到一半的文件被抽走；若卡在加载完成前被拔出，加载会失败并在下次挂载后重试。

指南针是未校准、未做倾斜补偿的二维磁航向，不是真北导航。固定顶部箭头下方的刻度值与上方角度读数一一对应。测试时保持模块水平，远离喇叭磁铁、铁件和大电流导线；默认模块 +Y 朝设备上沿、+X 朝右，实际轴向可通过 `HW_MAG_FORWARD_AXIS`、`HW_MAG_RIGHT_AXIS` 及对应符号配置。读数无效、水平分量不足或磁场过强时不显示指针。地磁初始化失败每 5 秒重试；串口输入 `mag status` 可查看地址 ACK、产品 ID、初始化/读取错误、状态位和三轴值。模块应为 MMC5983MA（7 位地址 0x30，产品 ID 0x30），不把不匹配器件按同一寄存器布局强行驱动。

## 硬件

目标为 ESP32-S3R8，外部 16 MB Flash，封装内 8 MB Octal PSRAM。

| 外设 | 配置 |
| --- | --- |
| ILI9341V 屏幕 | 240 x 320，SPI，CS10 / MOSI11 / SCLK12 / DC46 / BL45 |
| 屏幕复位 | 接 EN，不使用独立复位 GPIO |
| 共享 I2C | SDA16 / SCL15，100 kHz |
| FT6336G 触摸 | 地址 0x38，RST18；目前使用 10 ms 轮询，INT17 未启用 |
| MPU6050 | 地址 0x68 |
| MMC5983MA | 地址 0x30 |
| GNSS | UART1，RX44 / TX43，9600 baud |
| TF 卡 | SDMMC 4 位，CLK38 / CMD40 / D0=39 / D1=41 / D2=48 / D3=47；无独立插卡检测引脚 |
| ES8311 / FM8002E | I2C 地址 0x18，共享 SDA16 / SCL15；I2S MCLK4 / BCLK5 / DOUT8 / WS7；GPIO6 录音输入暂不启用；功放 GPIO1 低有效 |
| 电压采样 | 电池 GPIO9，供电来源 GPIO14；分压及阈值需匹配实际电路 |
| 控制台 | 原生 USB Serial/JTAG |

固定安装方向按加速度重力分量判定：X 约 -1 g 为正向竖屏，X 约 +1 g 为倒置；Y 约 +1 / -1 g 分别对应 90 / 270 度。姿态须稳定后才切换方向。

GNSS 使用 UART1 9600 baud，模块 TX 接 GPIO44（RX），模块 RX 接 GPIO43（TX），须共地并确认 3.3 V UART 电平。NMEA 解析支持 CRLF 和 LF 行尾；页面的 RX/TX 计数用于区分串口通信状态。TX 统计通过 `board_hardware_gnss_write()` 累计；当前固件不主动发送模块配置，因此 TX 为 0 属正常。Fix quality 为 0 时显示搜星中；室内通常因建筑遮挡无法获得定位，可移至室外并等待首次定位。指南针是陀螺快速积分和磁航向慢校正的互补结果，仍未校准、无倾斜补偿，不是真北导航；磁环境干扰仍会影响方向。

引脚与安装参数见 [main/hardware_config.h](main/hardware_config.h)，显示和天气参数见 [main/weather_clock_config.h](main/weather_clock_config.h)。ES8311 已接入触摸音与 WAV/内置旋律播放；GPIO6 麦克风录音仍未实现。

## 构建与烧录

使用已配置环境的 ESP-IDF 6.1，联网获取组件依赖。在本项目目录执行：

```sh
idf.py set-target esp32s3
idf.py build
idf.py -p COM12 flash monitor
```

`COM12` 是当前开发板示例端口，其他机器须替换为实际端口。也可通过 VS Code ESP-IDF 扩展选中本项目，并将目标设为 `esp32s3` 后构建、烧录。

组件版本由 [main/idf_component.yml](main/idf_component.yml) 和 [dependencies.lock](dependencies.lock) 管理。Flash、PSRAM、USB 控制台及字体默认值见 [sdkconfig.defaults](sdkconfig.defaults)。下载的组件与构建目录不进入仓库。

## 源码结构

- `main/hello_world_main.c`：应用入口、网络和控制台。
- `main/weather_clock.c`：页面布局、模式与数据刷新。
- `main/touch_controls.c`：滑动翻页、分页点淡出和骑行按钮。
- `main/display_port.c`：LCD、LVGL 和触摸适配。
- `main/board_hardware.c`、`main/board_power.c`：传感器与电压采样。
- `main/imu_view.c`：姿态箭头和 IMU 诊断。
- `main/tf_card.c`：SDMMC 挂载、状态探测和只读容量、目录快照。
- `main/entertainment_view.c`：系统滚动菜单、音乐/TF 文件/陀螺仪/地磁计/GPS/WiFi 二级导航及快照显示。
- `main/wifi_manager.c`：WiFi STA 状态机、扫描、连接与 NVS 凭据。
- `main/wifi_view.c`：WiFi 触摸配置界面与屏内键盘。
- `main/zh_font.c`：SD 卡中文字库载入 PSRAM 与 LVGL 文件系统驱动注册。
- `main/lunar.c`：公历转农历（1900-2100）。
- `main/usb_msc.c`：TF 卡 USB MSC（U 盘）模式与 TinyUSB 生命周期管理。
- `main/touch_sound.c`：ES8311 初始化、异步触摸短音、内置旋律/WAV 播放和休眠静音。
- `main/ride_model.c`、`main/weather_service.c`：骑行状态与天气服务。

## 公开上传注意事项

不提交 Wi-Fi 凭据、访问令牌、本机 SDK 路径或构建产物。首次使用前应核对引脚、电阻分压和传感器安装参数。电压估算不等同于充电状态，GNSS 无有效定位时不生成虚构速度或里程。
